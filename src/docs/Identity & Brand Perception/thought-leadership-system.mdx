# Thought Leadership Process

- **What it is:** Turn experience into original, defensible ideas.
- **Why it matters:** Define the few moves that create most of the results.
- **How to use:** Follow the checklist → ship → review → iterate.

- **Signals:** consistency, language, and social proof.
