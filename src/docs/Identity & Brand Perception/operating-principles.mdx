# ⚙️ Operating Principles — Founder Framework
*Concise, practical guide to define, deploy, and enforce how your company operates.*

## 1) What This Is
A founder-ready system to:
1) **Define** operating principles (the rules we *actually* run on)  
2) **Translate** them into behaviors, cadences, and artifacts  
3) **Measure & enforce** them so they drive decisions and outcomes

> If it doesn’t change behavior, it’s a poster—not a principle.

---

## 2) Definition
**Operating Principles:**  
Non-negotiable rules that guide decisions under uncertainty. They are **behavioral**, **teachable**, and **testable**.

**Structure (per principle):**
- **Name (2–3 words)**
- **Why it exists (1 sentence)**
- **Behaviors (do’s)**
- **Anti-Behaviors (don’ts)**
- **Signals/KPIs (evidence it’s lived)**

---

## 3) Draft in 30 Minutes (Founder Sprint)
1. **List 10 recent hard decisions.** What rule would have made them fast & right?  
2. **Extract 6–8 rules** that would generalize across product, growth, hiring.  
3. **Write them behaviorally** (what we do / never do).  
4. **Attach a KPI** to each (leading indicator).  
5. **Publish a one-pager** → train in weekly kickoff.

---

## 4) Canonical Principle Set (Examples)
Use these as starting points; rename to fit your culture.

1. **Customer Math First**  
   - *Why:* Emotions lie; unit economics don’t.  
   - **Behaviors:** Start briefs with CAC/LTV/MER; kill ideas that fail math.  
   - **Anti:** Shipping features without payback logic.  
   - **Signals:** % initiatives with ROI model ≥100%; kill rate on non-viable ideas.

2. **Speed with Guardrails**  
   - *Why:* Velocity compounds if risk is capped.  
   - **Behaviors:** 24–48h decisions; pre-set blast radius (time/budget caps).  
   - **Anti:** Infinite debates; open-ended pilots.  
   - **Signals:** Cycle time; % projects within guardrails.

3. **Proof over Opinion**  
   - *Why:* Reality wins.  
   - **Behaviors:** A/B before all-in; show 3 receipts (data, clip, customer).  
   - **Anti:** “Because I said so.”  
   - **Signals:** # experiments/week; win rate; % comms with evidence.

4. **Single-Owner Accountability**  
   - *Why:* Committees blur outcomes.  
   - **Behaviors:** One DRI per decision; public due date.  
   - **Anti:** Shared ownership of critical paths.  
   - **Signals:** On-time delivery; # escalations.

5. **Write then Build**  
   - *Why:* Writing clarifies thought; prevents waste.  
   - **Behaviors:** 1-pager PRD/brief before work; assumptions listed.  
   - **Anti:** Slack-driven scope.  
   - **Signals:** % work with briefs; rework hours.

6. **Tight Feedback Loops**  
   - *Why:* Short loops = fast learning.  
   - **Behaviors:** Weekly demos; postmortems ≤48h; customer calls weekly.  
   - **Anti:** Quarterly surprises.  
   - **Signals:** Time-to-signal; demo cadence; NPS changes post-iteration.

7. **Default to Transparency**  
   - *Why:* Hidden info slows teams.  
   - **Behaviors:** Open dashboards, public decisions, clear “why.”  
   - **Anti:** Need-to-know hoarding.  
   - **Signals:** Dashboard usage; decision logs published.

8. **Simple Beats Clever**  
   - *Why:* Simple scales, clever breaks.  
   - **Behaviors:** Fewer steps, fewer tools; remove before add.  
   - **Anti:** Tool sprawl; premature abstraction.  
   - **Signals:** SOP step count; tool count per workflow.

9. **Earned Autonomy**  
   - *Why:* Freedom follows competence.  
   - **Behaviors:** Expand scope after 3 consecutive wins.  
   - **Anti:** Blanket autonomy on day one.  
   - **Signals:** Promotion velocity; quality variance.

10. **Respect the Calendar**  
    - *Why:* Time is the only hard constraint.  
    - **Behaviors:** Hard start/stop; no meeting without owner/agenda/decision.  
    - **Anti:** Drift meetings; multi-tasking Zooms.  
    - **Signals:** Meeting kill rate; focus hours protected.

## 5) Operationalizing Principles (Make Them Real)

### 5.1 Cadences (Rituals)
- **Weekly Kickoff (30m):** Top 3 priorities; principle spotlight; KPI review  
- **Demo Day (30–60m):** Show receipts; decisions recorded  
- **Retro (20m/team):** 1 insight → 1 change → owner + date  
- **Hiring Loop:** Principle interview + work sample mapped to principles

### 5.2 Artifacts (Always-On)
- **Decision Log:** Date, owner, principle invoked, outcome  
- **Principle Cards:** One slide each (why, behaviors, KPI) in onboarding  
- **Scoreboard:** Public KPIs tied to each principle

---

## 6) Measurement & Enforcement

### 6.1 Scorecard (Monthly)
| Principle | KPI | Target | Actual | Note |
|---|---|---|---|---|
| Customer Math First | % briefs with ROI model | ≥90% |  |  |
| Speed with Guardrails | Cycle time (idea→ship) | ≤7 days |  |  |
| Proof over Opinion | # tests/week | ≥3 |  |  |
| Single-Owner | On-time delivery | ≥85% |  |  |

### 6.2 Accountability
- **Green:** Celebrate & replicate  
- **Yellow:** Coach; add constraint or training  
- **Red:** Change owner/process; consider role fit

---

## 7) Decision Protocol (When Principles Conflict)
1. **Company Survival > Customer > Team > Individual**  
2. If tie: **Math beats Mood**  
3. If still tie: pick **reversible** option; set a timer; test.

---

## 8) Hiring & Firing to Principles
- **Hire:** Work sample graded against top 4 principles  
- **Onboard:** First 30 days = 4 small wins mapped to principles  
- **Fire:** Repeated anti-behaviors after coaching (documented)

- **Day 1:** Founder draft (6–8 principles)  
- **Day 3:** Leadership edit; add KPIs  
- **Day 5:** All-hands teach; publish artifacts

## 11) Final Rule
> Principles aren’t beliefs—they’re **operating constraints**.  
If they don’t speed decisions, sharpen focus, and raise the win rate, rewrite them.

Ship v1 today. Improve monthly. Let behavior—not slogans—define your culture.
