# Monk Mode → Execution Protocol

## Principle
Design your day so deep work happens by default, not willpower.

## Core Idea
Constrain inputs, remove switching, and define start/stop triggers.

## Levers
- Environment: workspace, blockers, white-noise or silence  
- Input rules: notifications, apps, time windows  
- Output rules: daily deliverable, definition of done

## Takeaway
Monk Mode = fewer decisions + tighter constraints → more throughput.
