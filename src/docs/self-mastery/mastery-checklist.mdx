# 🧩 Mastery Checklist  

## 1. Overview

Mastery is not achieved — it’s maintained.  
It’s a lifelong audit of your habits, systems, and internal calibration.  
This checklist exists to **measure your evolution**, detect weakness early, and ensure that every version of you is sharper, calmer, and more capable than the last.

> “The man who measures himself cannot fall behind.”

Each section below contains **criteria for mastery**, broken down into **Mind, Body, Work, Systems, and Spirit** — the five dimensions of the tyrant’s self-command.

---

## 2. Mind Mastery 🧠  
*Focus, Clarity, and Emotional Control*

| Check | Description | Status (✅/⚠️/❌) |
|--------|--------------|----------------|
| ☐ | I wake up without phone input or digital noise. | |
| ☐ | I can maintain focus for 90 minutes without distraction. | |
| ☐ | I journal or reflect daily to clarify thought loops. | |
| ☐ | I am emotionally neutral under pressure. | |
| ☐ | I read or learn something daily that sharpens perspective. | |
| ☐ | I know my “why” for every project I pursue. | |
| ☐ | My thoughts are organized into systems, not chaos. | |

**Goal:** Achieve cognitive sovereignty — your attention serves you, not the world.

---

## 3. Body Mastery 💪  
*Energy, Discipline, and Physical Authority*

| Check | Description | Status (✅/⚠️/❌) |
|--------|--------------|----------------|
| ☐ | I train at least 4–6 days per week with intensity. | |
| ☐ | I fuel my body with clean, high-energy food. | |
| ☐ | I drink 2–3L of water daily and sleep 7–8 hours. | |
| ☐ | I maintain posture and presence that command respect. | |
| ☐ | My body reflects my standard — not convenience. | |
| ☐ | I use physical discomfort as a training ground for mental strength. | |

**Goal:** Command your physiology. The tyrant’s body is the instrument of his will.

---

## 4. Work Mastery ⚙️  
*Execution, Focus, and Long-Term Leverage*

| Check | Description | Status (✅/⚠️/❌) |
|--------|--------------|----------------|
| ☐ | I operate with a clear top priority each day (“One Thing Rule”). | |
| ☐ | I work from structured time blocks, not impulses. | |
| ☐ | I track KPIs or metrics that measure my true output. | |
| ☐ | I eliminate 80% of tasks that produce 20% of results. | |
| ☐ | My environment is optimized for deep work. | |
| ☐ | I delegate or automate anything that doesn’t require my mind. | |
| ☐ | I can describe my long-term game plan in one sentence. | |

**Goal:** Every action compounds toward an inevitable outcome — empire creation.

---

## 5. Systems Mastery 🧩  
*Structure, Order, and Operational Intelligence*

| Check | Description | Status (✅/⚠️/❌) |
|--------|--------------|----------------|
| ☐ | My goals are tracked in a dashboard or Notion board. | |
| ☐ | I review progress weekly, not sporadically. | |
| ☐ | I use templates, SOPs, and automations for repeat tasks. | |
| ☐ | I maintain a personal operating manual (habits, routines, rules). | |
| ☐ | I regularly refine my systems (Kaizen principle). | |
| ☐ | I can scale my work without losing control. | |

**Goal:** Systems make power sustainable — chaos cannot scale.

---

| ☐ | I live by a personal code of conduct. | |
