## Prime Directive & Operating Mindset

- **Prime Directive:** *Ship → Measure → Learn → Iterate.*
- **Bias to Action:** Imperfect and live beats perfect and never shipped.
- **Data over Ego:** Every result is a datapoint; decisions follow evidence.
- **Tool Leverage:** Use AI to compress research, drafting, creative, and analysis cycles.

### Guardrails (check all before each test loop)

- [ ] Time-box the experiment to **7–14 days**.  
- [ ] Define **success/fail thresholds pre-launch** (no moving goalposts).  
- [ ] Document inputs, changes, outcomes, learnings in the **Change Log** (see Governance).

## 3) Phase A — Topic Discovery (2–3 days)

### A1) Skill-Led Path

**Inputs:**
- Brain-dump 10–20 topics from skills, hobbies, and work wins.  
- For each topic, map **Audience → Problem → Outcome**.  
- Draft a **Unique Value Zone (UVZ)** (Market → Niche → UVZ).

*Example: Digital planners → Wedding planners → Destination wedding budget tracker.*

**Tasks:**
- [ ] Create a table listing topics with Audience/Problem/Outcome/UVZ.  
- [ ] Shortlist promising niches (notes + links to comps).

### A2) AI-Led Path

**Prompt — Topic Radar (paste into AI):**

You are a market analyst. Propose 20 digital-product topics that show proven buyer demand now. For each: (a) audience, (b) specific problem, (c) tangible outcome, (d) top 3 competing product angles, (e) where demand is visible (marketplaces/ad types), (f) initial price tier, (g) 3 UVZ angles.
Return as a table.

**Tasks:**
- [ ] Run prompt and import table to Notion.  
- [ ] Merge with A1 list and remove duplicates.

### A3) Scoring Matrix (choose 1–3 to validate)

**Weights:** Demand 0.35 • UVZ 0.20 • Monetization 0.20 • Build speed 0.15 • Skill 0.10

**Score Formula:**  
`Score = 0.35*Demand + 0.2*UVZ + 0.2*Monetization + 0.15*Build + 0.1*Skill`

**Tasks:**
- [ ] Score each topic (0–5 scale); rank by **Score**.  
- [ ] Select **1–3** topics for validation; archive the rest.

**Create a Validation database** (use CSV provided). Track: *Source, URL, Offer, Price, Hook, Proof used, Bonus stack, Gravity/Signals, Notes, Your UVZ improvement.*

**ClickBank (signals):**
- [ ] Filter relevant category; sort by **Gravity**.  
- [ ] Capture offers with **Gravity &gt; ~20**. Save pitch, hook, price, funnel.

**Meta Ads Library:**
- [ ] Search main keywords; log **advertiser count**, **ad age (&ge; 30–90 days)**, **creative variety**, **angles**.

**Marketplaces (Etsy/Gumroad/etc.):**
- [ ] Sort by top sellers/“bestseller”; capture **pricing, bundles, reviews** (pain/feature gaps).

- [ ] Export **50–200 reviews**; tag pain points, requested features, objections.

## 7) Phase E — Launch Traffic (Days 1–14 post-MVP)

### E1) Influencer Arbitrage (Start Here)

**Prospect List Build (Daily 60–90 min):**
- [ ] Instagram: search keywords/hashtags; open a suitable **micro-influencer (20–50k)** → use *Suggested* for peers.  
- [ ] Log: handle, followers, avg story views, reel views, niche fit, contact path.

**Qualification Targets:**
- [ ] &ge; **3%** engagement; &ge; **10k** recent reel views; consistent posting; positive growth; audience **17+**; geo fit.

**Viability Calculator:**

Potential Clickers = StoryViews × EngagementRate  
Potential Buyers   = Potential Clickers × ConvRate   (use 2–4%)  
Revenue            = Potential Buyers × Price

**Outreach Scripts:**
- **DM #1:** “Hey [Name], quick partnership idea for your audience—commission-only, no upfront. Open to details?”  
- **Follow-ups:** “Bumping this 👍 can I send a one-pager?” → “Last nudge—happy to circle back later.”

**Data Request (on positive reply):**
- Avg story views (7d), audience age/location, link clicks (30d).

**Deal Structure:**
- Commission **30–60%** per sale; unique affiliate link + coupon; **weekly/biweekly payout**.

**Simple Agreement (key terms):**
- Scope, disclosure **(#ad)**, tracking, payout timing, **refund adjustments**.

**Promo Kit (you provide):**
- 3-story sequence with copy, stickers, swipe-ups; 2 reels; 5 stills; CTA overlays; tracking links.

**3-Story Structure:**
1) Poll/Warm-up (“Want me to show you how to [Outcome]?”)  
2) Method + proof (screens, concise)  
3) CTA (“Early access for my followers—link here”) + urgency

**Compliance:** Ask for **#ad** or “paid partnership” tags.

**Daily Motion:** Aim **150 DMs/day**; follow up 2–3× daily for max 3 days; move on.

### E2) Paid Ads (After 1–3 sales/proof)

**Before You Spend:**
- [ ] Pixel/Tags firing; **Purchase** event verified.  
- [ ] Google Ads primary conversion set.

**Google Search — Setup:**
1) Campaign: Search → Website traffic → Manual CPC (enhanced) *or* Max Conversions (if events stable).  
2) Ad groups: **3–5 themes** (“notion planner”, “content planner template”, etc.).  
3) Keywords: **exact + phrase**; start with 10–30; negatives list (free, pirated, unrelated).  
4) Ads: **3 RSAs/ad group**; 10–12 headlines (benefit + UVZ + price + CTA), 4 descriptions.  
5) Budget: ≈ **product price/day**; locations where buyers are.  
6) Extensions: Sitelinks (Bonuses, What’s Inside, Guarantee), Callouts (Lifetime access, Instant download).

**Meta (FB/IG) — Setup:**
1) Objective: **Sales**; Conversion location = Website; Pixel = verified.  
2) Structure: **ABO** to start; **3–5 ad sets** (broad interests + lookalike if traffic exists).  
3) Creatives: **5 images + 5 videos**; use **AIDA &amp; PAS** copy formulas; limit to **3 angles**.  
4) Budget: ≈ product price/**ad set/day**; run **7 days**; kill bottom **30–40%** by CPA; duplicate winners.  
5) Placements: **Advantage+** initially; trim later.  
6) Landing page: **&le; 2.5 s** load; above-fold CTA; social proof.

**KPI Benchmarks (initial):**
- Click-thru (Search) **&ge; 4–6%**; (Meta) **&ge; 0.8–1.5%**  
- LP CVR **2–5%** (cold); **6–12%** (warm)  
- CAC **&le; 30–50%** of price at MVP stage; **ROAS &ge; 1.5×** target in tests.

### E3) Organic Content (Compounding)

- **Faceless shorts:** 3–5/week → Hook → Micro-lesson/demo → CTA.  
- Align topics to product **outcomes**.

**Hook Starters:**
- “I wasted 6 months doing X—do this instead.”  
- “3 Notion tweaks that doubled my output.”  
- “Steal my [template] that saves 4 hrs/week.”

**CTA:** “Get the exact template (link in bio).”

### E4) Profile Ads & Story Conversion Funnel (Pro)

**Objective:** Drive ICP to your **IG/FB/LI profile** with *Profile Ads*, nurture with daily **Stories &amp; feed**, and convert via **Story Ads (retargeting)** + **DM → Setter → Call → Close**.

**Outcome:** Lower CAC vs VSL funnels; fast signal on creative-market fit; compounding profile asset.

### Prerequisites

- [ ] **Business Manager** connected to IG/FB profile; ad account verified.  
- [ ] **Pixels/Events** active (IG account engagement audiences enabled; GA4/Meta Pixel on booking site if used).  
- [ ] **Asset Library** created: #1 Video (pattern interrupt), #2 Carousel (results), #3 One-Pager (offer reframe).  
- [ ] **Daily Story Sequence** template: *Proof → Lesson → Offer → CTA*.  
- [ ] **DM Keyword** and ManyChat (or native IG auto-reply) flow live.  
- [ ] **Setter calendar** + reminder automations (24h/4h/1h) and **No-show rebook** sequence.  
- [ ] **Tracking Sheet** columns added: date, spend, **profile visits**, **CPV**, followers, **$/qualified follower**, convos, booked, show, closed, units, revenue, ROAS.

### C1 — Profile Ads (Traffic to Profile, ABO)

- **Objective:** Engagement → *Instagram profile visits* (or Reach/Engagement optimizing for 2s video if not available).  
- **Ad Sets (start 3):**  
  - *Broad Cold* (no interests)  
  - *Entrepreneurship* interest  
  - *Open Broad* with advantage targeting  
- **Placements:** Manual → IG Stories, IG Reels, IG Profile Reels.  
- **Geo/Age:** 20–50, all genders; set markets per ICP.  
- **Budget:** $150/day per ad set (or ≈ product price/day if earlier stage).  
- **Creatives (10–15):** Mix of **#1 Video**, **#2 Carousel**, **#3 One-Pager**. CTAs: *Visit Profile*, *DM “[keyword]”*.  
- **Notes:** Exclude recent purchasers if site pixel exists; **do not** exclude engagers here (you want profile growth).

### C2 — Story Ads (Retargeting, ABO)

- **Objective:** Messaging or Traffic → *Book/DM*.  
- **Audiences (separate ad sets):**  
  - IG account **180-day engagers**  
  - **Video viewers** 25–95% (last 180d)  
  - **Story viewers** (last 90–180d)  
  - **Post engagers** (last 180d)  
  - **Site visitors / Lead Magnet opt-ins** (last 30–180d)  
- **Placements:** IG Stories + IG Reels.  
- **Budget:** $150/day per ad set; consolidate to winners after 3–5 days.  
- **Creatives:** **Story Ad System** = *Proof → Lesson → Offer → CTA*; **Objection assets** (price/time/risk/fit); **One-Pager reframe**; **Results carousel**.  
- **Messaging:** 2 CTAs per story (~65% and 100% progress). **Messenger Ads** with CTA *DM me “[keyword]”* (auto-reply delivers LM + booking link).

### Creative & Story Systems

- **Hook → Body → CTA** (hook = curiosity in first 3s, e.g., “11k/month” beats “10k”).  
- **Daily Story Sequence:** *Curiosity → Mechanism → Data → Solution → Proof → Credibility → CTA*.  
- **Dynamic Asset Library:** Tag each asset by stage (**Traffic / Nurture / Conversion**) &amp; objection handled.  
- **Testimonials:** Editor packages **client results → proof reels**; boost top ones as RT ads.

**Prompt — Profile Ad Copy (paste into AI)**

Write 5 Instagram profile ad scripts for [AVATAR] to achieve [OUTCOME] using [MECHANISM].
Each: 3s hook, 2 lines body, 1 CTA to “Visit profile” + optional “DM [KEYWORD]”.
Return as table: Hook | Script | CTA | Angle (proof/lesson/offer).

**Prompt — Story Ad Sequence (paste into AI)**

Add overlays, sticker suggestions, two CTAs (frame 5 and frame 7), and an objection variant for [OBJECTION].

### Automations &amp; Hand-offs

- **Ad Click → Profile Visit** seeds RT audiences automatically.  
- **Profile follow / Story interaction** → Engager starts warm outbound.  
- **DM “[keyword]” auto-reply** → Setter receives convo + **booking link + pre-qual**.  
- **Booked** → calendar invite + **SMS/email reminders** (24h/4h/1h).  
- **No-show** → **Re-book 2nd Call** + objection-led RT assets.  
- **Closed-won** → onboarding tasks; **testimonial request at first milestone**; Editor packages proof → RT.  
- **Churn risk** → CSM save offers (downgrade/continuity perks).

### Roles &amp; Ownership (Swimlanes)

- **Growth Specialist** — Own traffic (#1 Video, #2 Carousel, #3 One-Pager), manage RT audiences/budgets, weekly iteration.  
- **Content Manager** — Own nurture (SF/LF calendar), daily Story sequence, lead magnet alignment, curate dynamic assets.  
- **Editor** — Cut/caption shorts; produce carousels/one-pager; edit testimonials; maintain versioning.  
- **Engager** — Reply to comments/DMs; warm outbound to engagers; micro-qualify; trigger follow-up; hand-off.  
- **Apt Setter** — DM re-qual → booking link; reminders; no-show rebook path.  
- **Closer** — Discovery → Offer; follow-ups if no close.  
- **CSM** — Onboarding within 48h; access checklist; success cadence; request testimonials.

### KPI Benchmarks (initial)

- **Traffic:** CTR, CPC, **Profile Visits**, View-through %. **CPV &le; $0.20** target.  
- **Profile/Nurture:** Follower → Convo %, Story reach, **Story reply rate**, Lead Magnet CVR.  
- **DM/Setting:** **Qualified % &ge; 30%**, **New conversation start &ge; 80%**, **Booked call $80–$100**.  
- **Sales:** Show &ge; **75%**, Close %, **ASP $3k–$15k**, Sales cycle (days).  
- **Global:** CAC, LTV, Payback, **ROAS 8–15×** (examples include 10×/15×/30× on small spend).  
- **Scaling guardrail:** Profile ads often cap around **£300/day** (~£10k/month) before efficiency decays.

### Daily/Weekly Operating Rhythm

- **Daily:**  
  - Post Stories (7-frame sequence) &amp; 1–2 SF posts; refresh top story creatives.  
  - Engager clears inbound; warm outbound to engagers.  
  - Setter books, runs reminders, rebooks no-shows.  
- **Weekly:**  
  - Rotate in 3–5 new creatives; archive bottom **30–40% by CPA/CPV**.  
  - Consolidate budgets to top ad sets/creatives; expand geos only after stability.  
  - Update Tracking Sheet; review KPIs vs benchmarks; document learnings.

### Implementation Checklist

- [ ] **C1 Profile Ads** live (3 ad sets, manual IG placements, 10–15 creatives).  
- [ ] **C2 Story RT** live (&ge; 3 audience types, objection assets included).  
- [ ] **DM keyword** + auto-reply flow tested end-to-end.  
- [ ] **Setter** SLAs (reply within 10 min in hours; reminders 24h/4h/1h).  
- [ ] **No-show** rebook path active.  
- [ ] **Testimonial cadence** defined; first milestone trigger set.  
- [ ] **Tracking** validated (CPV, $/qualified follower, booked CPA, show %, close %, ROAS).

**Proceed to scale** when, over 3 consecutive days: **CPV &le; $0.20**, **$/qualified follower &le; $13–$14**, **Booked CPA &le; $100**, **Show &ge; 75%**, and **ROAS &ge; 8×** on RT spend.

## 8) Phase F — Pricing, Offers, Monetization Ladder

**Objective:** Design a monetization ladder and attach the right **Money Models** (attraction, upsell, downsell, continuity) to maximize **CVR, AOV, LTV, and Payback** while keeping CAC in check.

### F1) Monetization Ladder (set ranges &amp; SKUs)

- **Gateway** (lead-in): $9–$49 — ebook/worksheet/mini-tool.  
- **Core** (primary SKU): $29–$149 — templates/toolkits/mini-course.  
- **Advanced** (flagship): $149–$999+ — full system/automation/white-label.  
- **Continuity** (MRR): $9–$49/mo — updates/community/automation credits.  
- **Attach Points:** Attraction → Gateway/Core → **Upsell** → **Continuity**; failed/hesitant buyers → **Downsell**.

**Offer Flow (default):** *Attraction* → Landing → Core Checkout → **Post-purchase Upsell** → **Continuity Pitch (Day 10/Onboarding)** → **Downsell** (if exit/decline) → **Re-targeting Loop**.

### F2) Money Models — Catalog &amp; Selection

**A) Attraction Offers (TOFU lead capture &amp; profile growth)**  
- **Win Your Money Back:** Goal-based refund/store credit on proof of completion.  
  - *Use when:* High-confidence outcomes; you can define clear success criteria.  
  - *Guardrail:* Plain-English terms; verification steps; time window.  
- **Giveaway:** Prize in exchange for contact info/DM keyword.  
  - *Use when:* List growth needed; seasonal promos.  
  - *Guardrail:* Eligibility, dates, winner selection, region/legal.  
- **Decoy:** Present free/discounted entry alongside a premium option to anchor value.  
- **Buy X Get Y Free:** Bundle incentive (e.g., Core + Bonus Pack).  
- **Pay Less Now or More Later:** Early decision discount + bonus stack; standard price later.

**B) Upsell Offers (increase AOV/solve next problem)**  
- **Classic Upsell:** Offer the step-two solution immediately after purchase.  
- **Menu Upsell:** Advise what to skip vs buy; curated path by avatar.  
- **Anchor Upsells:** Show highest-tier first; down-shift if balk.  
- **Rollover Upsells:** Credit prior purchase toward the next offer.

**C) Downsell Offers (salvage revenue; improve access)**  
- **Payment Plan Downsells** • **Trial with Penalty** • **Feature Downsells (Lite)**

**D) Continuity Offers (stabilize LTV; compounding value)**  
- **Continuity Bonus Offer** • **Continuity Discount Offers** • **Waived Fee Offers**

### B) Influencer One-Pager (paste into doc)
- **What:** [Product] for [Avatar] to achieve [Outcome].  
- **Why it works:** 3 bullets (proof/benefits).  
- **Commission:** __% of each sale; weekly payouts.  
- **How to promote:** 3-story sequence + link.  
- **Tracking:** Unique affiliate link + coupon.  
- **Disclosure:** Use #ad or paid partnership tag.

### C) Mini Affiliate Agreement (extract)
- **Scope:** Promote [Product] via social posts/stories.  
- **Tracking:** Sales via unique link/coupon only.  
- **Commission &amp; Payouts:** __% net, paid weekly; refunds deducted.  
- **Content:** Must follow platform policies; no misleading claims.  
- **Termination:** Either party can terminate with 3-day notice.

### D) VSL Script Outline (3–4 min)
1. Problem &amp; stakes (30s)  
2. Mechanism/UVZ (45s)  
3. Demo/What’s inside (60s)  
4. Proof &amp; objections (45s)  
5. Offer, bonuses, guarantee, CTA (30s)

### E) Ad Copy Starters
- **PAS:** Problem → Agitation → Solution (+ CTA)  
- **AIDA:** Attention → Interest → Desire → Action

### F) QA Launch Checklist
- [ ] Payments live; **test purchase OK**.  
- [ ] Pixel/Tags fire; conversions recorded.  
- [ ] Download link works; email delivery sent.  
- [ ] Page loads **&le; 2.5 s**; mobile optimized.  
- [ ] All **UTMs** verified; no 404s.
