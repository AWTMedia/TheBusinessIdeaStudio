# Team Directory &amp; Roles (RACI + Rituals)

A **Team Directory** ensures everyone knows who owns what, how to collaborate, and when to meet.  
It provides clarity around **roles, interfaces, and operating cadence** so teams can move faster with fewer bottlenecks.

---

## 🧭 What It Is

A structured system for:
- Assigning ownership and accountability across projects.  
- Mapping workflows using the **RACI model** (Responsible, Accountable, Consulted, Informed).  
- Creating clear communication channels and recurring team rituals.  

This document acts as your **team’s control panel**, connecting people, systems, and SOPs into a cohesive rhythm.

---

## 💡 Why It Matters

When roles and rituals are unclear, teams duplicate work, miss deadlines, and lose focus.  
By defining ownership and cadence upfront, you can:

- Eliminate confusion around who’s responsible for what.  
- Improve collaboration and information flow between departments.  
- Ensure consistent project execution through predictable check-ins.  
- Create accountability and reduce dependency on reactive communication.

&gt; “Clarity scales. Confusion multiplies cost.”

---

## ⚙️ How to Use

1. Review all key projects and functions.  
2. Assign owners (RACI) for each — including backups if applicable.  
3. Define communication channels (Slack, Notion, meetings).  
4. Set a cadence for reviews, syncs, and retrospectives.  
5. Ship → Review → Iterate (update quarterly or when structure changes).

## 🧩 Core Artifacts

| Artifact | Description | Owner | Cadence |
|-----------|--------------|--------|----------|
| **SOPs** | Step-by-step operating procedures for recurring workflows | Ops Lead | Updated monthly |
| **Checklists** | Tactical execution lists for tasks and deliverables | Function Owner | Used per sprint |
| **Owner Matrix** | RACI mapping per project | Project Manager | Updated per cycle |
| **Cadence Calendar** | Weekly &amp; monthly meeting rhythm | Ops Coordinator | Reviewed quarterly |

---

## 🧠 The RACI Framework

| Role | Definition | Example |
|------|-------------|----------|
| **R – Responsible** | The person doing the work or task. | Social Media Manager posting content |
| **A – Accountable** | The person owning the outcome and sign-off. | Marketing Director |
| **C – Consulted** | Provides input, guidance, or domain expertise. | Content Strategist |
| **I – Informed** | Needs updates or visibility but not active involvement. | Executive Team |

Use this to define each major workflow or deliverable.  
One person should always be **Accountable**, even if multiple are **Responsible**.

---

## 📅 Team Rituals

| Ritual | Frequency | Purpose | Owner |
|---------|------------|----------|--------|
| **Weekly Ops Sync** | Weekly | Review performance, unblock tasks, set next sprint | Ops Lead |
| **Strategy Meeting** | Bi-weekly | Align teams on goals, campaigns, and KPIs | Leadership |
| **Performance Review** | Monthly | Analyze results, iterate processes | Team Leads |
| **All-Hands** | Quarterly | Share wins, roadmap, and updates | CEO / Founder |

### Optional Add-ons
- **Daily Stand-ups:** For fast-moving teams; 10–15 min updates.  
- **Async Updates:** Use Notion/Slack threads for remote visibility.  
- **Retro Sessions:** End of each month; capture lessons and improvements.

## 🔁 Review &amp; Iteration

Every quarter:
- Reconfirm ownership per workflow.  
- Evaluate bottlenecks and communication loops.  
- Archive outdated roles and introduce new ones as needed.  
- Ensure all artifacts link to updated SOPs and documentation.
